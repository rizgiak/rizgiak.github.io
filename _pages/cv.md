Selected Projects
=================

Two-Fingers - In-Hand Manipulation, Master's Thesis (2021-2023)

- Developed a two-finger gripper hand capable of in-hand manipulation using active fingertip joints while moving an uncommon-shaped object from its initial to its desired position.
- Increased the success ratio to 100% by analyzing force control, object surfaces, and pressure during sequential movement.
- Created visualization in RViz and simulation in Gazebo to simplify debugging and comparison of the theoretical approach.
- Utilized: Linux, C/C++, Python, Arduino, ROS, RViz, Gazebo, Cobotta, Dynamixel, Git, Fusion 360

[F.A.S.T. (Flow Axial Seal Tip)](https://formulatrix.com/liquid-handling-systems/fast-liquid-handler/), Formulatrix (2019-2021)

- Team-developed an object recognition algorithm using blob detection to recognize the number and position of up to 384 tips.
- Team-developed a system using TensorFlow and Coral.ai to recognize unordered or fallen tips and prevent collisions by stopping the sequence.
- Created an algorithm that enables the system to enter recovery mode after a collision instead of rebooting the system.
- Utilized: Linux, C/C++, C#, MSTest, Raspberry Pi 3/Zero, OpenCV, Git, CI/CD, camera calibration

Walking Control for EROS Humanoid Robot on ROS Platform, Bachelor's Thesis (2018-2019)

- Designed the overall system for humanoid robots using a single high-level controller.
- Created a walking control system using inverse kinematics and a walking trajectory generator.
- Reduced the RMS error of walking stability by 35% by implementing an inverted pendulum approach.
- Utilized: Linux, C/C++, XML, ROS, YAML, RQT Plot, Arduino, PID control, high-speed serial communication

[KidSize Humanoid Robot Soccer (EROS)](http://anhar.lecturer.pens.ac.id/projects/eros/) - Robotic Team (2016-2019)

- Developed five autonomous humanoid robots capable of walking, recovering from falls, recognizing and shooting the ball, coordinating, and self-positioning on the field.
- Created an object recognition system for the field using machine learning.
- Created an optimized algorithm with cascaded finite-state machines to reduce self-decision time.
- Developed a wireless debugging system for all robots during soccer competitions.
- Utilized: Linux, C/C++, PHP, Shell, ROS, STM32F4, OpenCV, MATLAB, TCP/IP communication, Git
